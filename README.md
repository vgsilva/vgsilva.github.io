# Portfólio Pessoal (em eterna reconstrução)

Este é o meu portfólio pessoal desenvolvido com HTML5, CSS3 e JavaScript, criado para apresentar minha trajetória como estudante de Sistemas de Informação, meus projetos e minhas habilidades em desenvolvimento de software.

O objetivo deste projeto é servir como um ponto central para que recrutadores e profissionais da área conheçam meu trabalho, acompanhem minha evolução e acessem meus principais projetos.

## Funcionalidades

* Apresentação profissional
* Seção "Sobre mim"
* Lista de projetos
* Informações de contato
* Alternância entre tema claro e escuro
* Layout responsivo
* Interface moderna utilizando HTML e CSS

## Tecnologias

* HTML5
* CSS3
* JavaScript
* Google Fonts

## Como executar

Clone o repositório:

```bash
git clone https://github.com/vgsilva/portfolio.git
```

Abra o arquivo `index.html` em qualquer navegador.

## Objetivo

Desenvolver um portfólio moderno e de fácil navegação para apresentar projetos, competências técnicas e evolução profissional como desenvolvedor de software.

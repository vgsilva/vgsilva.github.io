Sobre Mim

Olá, tudo bem?


Meu nome é Vinicius Gomes, um desenvolvedor Front-End do Rio de Janeiro - RJ, Brasil. Estou cursando o sexto período do bacharelado em Sistemas de Informação na instituição IBMR. Sou apaixonado por desenvolvimento web, Javascript, eficiência e soluções elegantes.


Meu foco é criar soluções modernas e eficientes com código limpo e organizado. Tenho experiência em front-end, back-end e ferramentas modernas de desenvolvimento.

Projetos

Projeto 1 - Gerador de Piadas

Um site que faz uso de API para exibir piadas relacionadas a programação.

Projeto 2 - Batalha contra o Dragão

Desenvolvimento de um jogo de RPG utilizando HTML5, CSS3 e JavaScript, implementando funcionalidades como sistema de combate, gerenciamento de inventário, progressão do personagem, controle de experiência (XP), manipulação do DOM e gerenciamento de estado da aplicação. O projeto foi desenvolvido para consolidar conhecimentos em lógica de programação, desenvolvimento web e construção de interfaces interativas.

Projeto 3 - Ordenador de Números

Um projeto em que trabalhei com algoritmos fundamentais de ordenação, como bubble sort, selection sort e insertion sort utilizando Javascript.

Projeto 4 - Meu Portfólio

Um site de portfólio single-page com design clean, eficiente e uso de cores frias.
